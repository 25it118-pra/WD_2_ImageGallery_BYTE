# ArtVista - Image Gallery

A responsive image gallery with a lightbox feature developed as part of the ArithMatrix Web Development Internship.

## Features

- Responsive image gallery
- Lightbox image viewing
- Hover effects
- Mobile-friendly layout
- Clean and simple user interface

## Technologies Used

- HTML5
- CSS3
- JavaScript

## Project

ArtVista allows users to explore images and view them in an enlarged lightbox when clicked.
